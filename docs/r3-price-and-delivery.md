# MSG0585 비공개 가격·배송 검토

기존 제품의 `calculateQuote`, exact 산술, 고객 응답 projection을 IA 서버 번들에서 사용한다. 원본 커밋과 파일 해시는 `src/server/order-engine/SOURCE.json`에 있다. 가격 편집·승인과 견적 스냅샷은 기존 OWNER 세션과 CSRF 검사 뒤, 리뷰 업무 DB의 별도 소속·사업장 인증을 요구한다.

- 가격 편집 주소는 `/ia?view=pricing-r3`다. 공급처·거점·상품 배정에는 `r3_membership`과 `r3_price_scope`의 활성 행이 필요하다.
- 업무 배정이 없는 검토자는 `/ia?view=pricing-r3&practice=1`에서 내 연습 공간을 열고 합성 예시를 불러온다. 공급처로 저장·미리 계산·제출하고, 운영 검토자로 전환해 같은 버전을 열어 승인한다. 인증 사업장 예시로 전환하면 해당 가격의 견적 발급과 재조회가 가능하다. 연습 공급처와 운영자는 동일 사용자가 선택하는 **합성 역할**이다. 실제 2인 승인 검증은 별도다.
- 업무 버전 원장과 연습 버전 원장은 물리적 테이블이 다르다. 연습 접속은 세션에서 유도한 개인 공간으로 제한된다. 일반 DB에 연습 가격이나 일반 사용자 역할을 추가하지 않는다.
- 견적은 한 번 발급할 때 대상 SKU, 공급처, 사업장, 확정 배송지, 요청 revision, 선택한 가격·지역 규칙과 7일 만료시각을 저장한다. 동일 요청의 재전송은 기존 ID로 돌아온다. 기발급 비용은 기존 스냅샷에서 읽으며 권한·인증을 다시 확인한다.
- 규칙 충돌이나 자가승인이면 D1 트리거가 저장을 거절한다. 유효기간 겹침은 같은 공급처·거점·상품·포장·단위에 대해 차단한다. 예시 배송비는 실제 가격표에서 가져오지 않는다.

## 확인할 수 있는 조건

| 항목 | 검토 |
|---|---|
| 이번 10포장·합성 단가 25·기본배송 5 | 합성 공급처 초안에서 255원 예상. 공급처가 직접 승인하면 거절되고, 별도 운영 검토자가 승인한 뒤 인증 사업장 예시가 255원으로 발급한다. |
| 9포장·최소 10 | 수량 구간이 존재해도 배송/주문 가능으로 확정되지 않는다. |
| 전월 100·이번 10 | 전월 수량이 구간을 고르며 상품금액은 이번 수량으로 계산한다. 실적이 조회 실패/미확정이면 해당 정책의 계산을 중단한다. |
| 가격 갱신·배송비 변경 | 후속 버전을 저장한다. 기존 견적은 원 금액·만료시각으로 남는다. 유효기간이 7일보다 짧고 보장 근거가 없으면 발급을 차단한다. |
| 지역·묶음 | 행정구역 코드/버전·우편번호·요일·시각·우선순위를 대조한다. 여러 품목이 같은 출고·같은 배송지/회차에 속하면 한 번 부과한다. 지역 협의·불가·미설정은 금액으로 대체하지 않는다. |

## 실제 연결 범위와 판단이 필요한 정책

| 쟁점 | 가능한 운영 선택 및 영향 | 현재 구현 |
|---|---|---|
| 전월 실적 | 주문확정/납품완료, 고객/사업장/공급처/SKU/묶음, 취소·반품 차감 시점에 따라 가격 구간이 달라짐 | 규칙 식별자·서울 월 경계·버전으로 일치하는 서버 확정 실적을 읽는다. 거래 원장 자동 수집 및 취소·반품 확정 기준은 추가 운영 결정이 필요하다. |
| 세금·묶음 | 포함 또는 별도 세율, 배송 건별/사업장별/포장별, 반올림 방법에 따라 비교 총액이 달라짐 | 명시 입력을 요구한다. 합성 예시의 세금·반올림·배송 요금은 연습 원장에만 저장한다. 복합 할인, 혼합 단위의 배송 구간 환산은 보류한다. |
| 공급가 만료와 발급 보장 | 발급 7일 보장 또는 사전 재확인 | 7일 보장 기간 내에 승인 가격이 먼저 만료되면 발급을 차단한다. 철회 후 이미 발급한 견적 표시는 원본을 보존한다. |
| 절감율·연간액 | 동일 조건의 확인된 현재 비용과 연간 실제 횟수가 있어야 함 | 사전 검증한 입력으로 QA 미리 계산이 가능하다. 현재 업무용 견적 발급에는 신뢰할 실거래 비교 비용 원장이 연결되지 않아 해당 금액을 표시하지 않는다. |
| 지역 배송 | 관리 주체·지역 코드 버전·가입 사업장 확인 주소·거점 배정이 필요 | 서버가 확인한 사업장·배송지·승인 해외 아닌 국내 코드 범위에서 계산한다. 이름만 같은 곳이나 임의 선택 지역은 발급 대상으로 사용하지 않는다. |

## 근거와 복구

테스트는 `tests/r3-price.test.mjs`, `tests/r3-price-browser.py`와 원본 제품의 `test/engine/supply-policy-0585.test.mjs`다. 물리 D1 합성 검증과 실제 소유자의 로그인·상용 자격 검증은 별도 근거로 기록한다.

배포를 되돌릴 때 이전 검증된 IA 코드를 복원하면 새 경로가 닫힌다. DB의 과거 버전/이력/견적은 보존한다. 업무 원장 0002와 합성 원장 0005의 테이블을 삭제하거나 역할 권한을 자동으로 부여하는 rollback 작업은 포함하지 않는다.
