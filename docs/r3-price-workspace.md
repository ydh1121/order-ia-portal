# 단가표 작업공간

`/ia?view=pricing-r3`은 단가표, 판매 상품, 상품 분류, 배송수단 및 운임의 네 메뉴를 제공한다. UI는 `mountPriceWorkspace`로 분리해 이후 관리자 화면에 같은 편집기를 삽입할 수 있다. 실제 계약 가격과 발급 견적은 기존 `mode=contract`, `priceVersion`, `quote`, `practice` 경로를 계속 사용한다.

## 저장과 적용 범위

`r3_price_workspace_event`는 계정별 구성 이력이다. 임시저장, 즉시 반영, 예약 반영을 추가 행으로 기록하고 수정·삭제하지 않는다. `expectedRevision`을 비교해 오래된 창의 저장을 거절한다. 응답을 잃은 저장은 같은 요청 키로 재생한다. 예약 시각이 지난 후에도 원래 성공 결과를 반환한다.

현재 적용본은 서버가 `effective_at <= serverTime`인 반영 이력 중 최신 시각을 선택한다. 임시저장은 현재 적용본을 바꾸지 않는다. 예약 반영에는 열린 브라우저가 필요하지 않다. 화면의 현재 적용본·예약 목록은 서버 메타데이터를 조회해 표시하며, 조회가 편집 중인 문서를 교체하지 않는다.

구성의 반영은 이 계정의 단가표에 적용된다. 기존 상업용 `r3_price_version` 승인, 공급처·사업장 배정, 견적 발급 권한을 대신하지 않는다. 카드와 현금의 판매가격은 동일하고 PG 조정은 마스터의 원가 편집이다.

## 기존 자료 보존

첫 진입 때 기존 개인 초안의 활성 날짜에 속한 난각별 기본 행렬을 읽는다. `r3_personal_price_edit`는 변경하지 않는다. 원란·완제품 최종가, 원란 공백, `협의`, `미판매`, 소수 금액을 보존한다. 완제품 최종가가 원란보다 작은 경우에도 자동으로 올려 쓰지 않는다.

기존의 모든 날짜와 포장별 `packMatrices`, 포장 규칙은 구형 편집기의 원본 자료로 유지한다. 새 화면의 **기존 날짜·포장별 자료 열기**에서 해당 자료를 별도 창으로 열 수 있다. 이 자료 전체를 새 마스터의 비용 모델로 자동 이관했다고 간주하지 않는다.

## 분류와 이동

난각번호는 큰 번호부터, 계란규격은 무게가 큰 순서로 정렬한다. 새 분류 트리는 날짜 → 난각번호 → 규격 → 포장 구조다. 앞의 세 단계는 의미가 고정돼 있다. 포장을 같은 규격 안에서 끌면 포장 순서를 바꾸고, 다른 규격에 놓으면 포장비·배송수단 연결을 이동·복사·맞바꿀 수 있다.

대상에 비용이나 배송 설정이 있으면 덮어쓰기를 거절한다. 맞바꾸기를 선택하면 양쪽 값을 보존한다. 서로 다른 난각의 구간별 비용은 최소·최대 판수가 일치할 때만 옮긴다. 원래 연결을 미사용으로 바꿔도 그 비용은 지우지 않으며, 다시 연결할 수 있다. 기본 원란 행렬은 이동하지 않는다.

## 엑셀

공개 `price-template.xlsx`에는 열 이름, 난각번호, 규격, 포장 구수와 빈 금액 입력 칸만 있다. 실제 원가·사업자·계정 자료를 넣지 않는다. 기본 원가는 인증된 API에서만 읽는다.

입력은 `.xlsx`, `.csv`, `.tsv`를 지원한다. XLSX는 브라우저에서 ZIP/OpenXML 값을 읽고 외부 관계·매크로·수식을 실행하지 않는다. 수식은 저장된 계산 결과만 표시한다. 업로드는 8MB, 압축 해제 총량 24MB, 20시트, 시트당 3,000행·80열로 제한한다. 저장 본문은 2MB 이하로 검증한다.

비용 가져오기는 기본적으로 같은 최소 판수의 행을 병합하고 미포함 구간을 남긴다. 확인창에서 전체 구간 교체를 선택했을 때만 파일에 없는 구간과 그 구간 비용을 제거한다. 분류 파일에 없는 배송수단 열, 구간별 비용, 미사용 연결 상태는 보존한다. 모든 가져오기는 미리보기와 검증을 거쳐 편집 문서에 적용한 뒤 별도로 저장한다.

- `node --test tests/r3-price-workspace.test.mjs`: 원본 152개, 기존 조건값, PG 왕복, 구간, 분류 이동·충돌, 서버 예약, 요청 재생, 계정 격리, CSRF, 실제 XLSX와 부분 가져오기.
- `node tests/r3-price-workspace-dom.mjs`: 실제 페이지 → 인증 API → SQLite 저장, 메뉴, 배송 셀 선택, 트리, 버블 삽입, 날짜 폴더, 예약 피커, 늦은 조회·응답 유실.
- `node tests/r3-bundled-clients.mjs`: Wrangler의 함수 이름 보존 변환 뒤 클라이언트 부트스트랩.
- `python tests/r3-price-workspace-browser.py`: Chrome에서 320·390·768·1440 너비, 필터 표 너비, 저장 후 재조회, PG, 선택, 예약 피커.

자동화된 테스트는 격리된 서명 계정과 SQLite를 사용한다. 실제 계약 승인·고객 결제 완료를 의미하지 않는다.
